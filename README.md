## 🚀 Como instalar

> **Requisitos:** Windows 10 (1809 ou mais novo) ou Windows 11, 64 bits. Não precisa instalar mais nada.

1. Clique no botão **BAIXAR SAKA SS** acima.
2. Abra o `SakaSS_Setup.exe` e aceite o pedido de Administrador (necessário para criar a conexão VPN).
   - Se aparecer *"O Windows protegeu o computador"*, clique em **Mais informações → Executar assim mesmo**.
3. Clique em **INSTALAR**. Se você já tiver uma versão instalada, o botão vira **ATUALIZAR**.

## 🔑 Como entrar

1. Abra o Saka SS e clique em **OBTER KEY**.
2. Conclua os passos na página que abrir no navegador e copie a sua key.
3. Cole a key no app e clique em **ENTRAR**. Ela fica salva até expirar; depois é só gerar outra.

## 🌍 Como usar

1. Escolha um país e clique em **CONECTAR**.
2. Com o **Modo Discord** ligado (padrão), só o Discord usa a VPN — jogos, navegador e downloads não são afetados.
3. Deixe marcada a opção **Reiniciar o Discord ao conectar** para o Discord já usar a VPN.

## 🛠️ Problemas?

| Sintoma | O que fazer |
|---|---|
| "Nenhum servidor respondeu" | Clique em **ATUALIZAR** e tente outro país. |
| O Discord não muda de região | Clique em **REINICIAR DISCORD** depois de conectar. |
| O antivírus apagou arquivos | Adicione `C:\Program Files\Saka SS` às exceções e reinstale. |
| Outro problema | Abra **SOBRE → ABRIR LOGS** e envie o arquivo `sakass_AAAAMMDD.log` mais recente. |

Para desinstalar: *Configurações do Windows → Aplicativos → Saka SS → Desinstalar*.
